# مصاريفي — الإصدار 5

تطبيق شخصي بخمس لغات: العربية، التركية، الإنجليزية، الفرنسية، والكردية الكرمانجية بالحروف اللاتينية (Kurmancî). جاهز للرفع إلى GitHub Pages دون بناء أو مفاتيح API.

## رفعه على GitHub

1. فك ضغط الحزمة.
2. أنشئ مستودعًا باسم `masarifi`، أو افتح مستودع البرنامج الحالي.
3. ارفع **محتويات مجلد التطبيق**: يجب أن يكون `index.html` في جذر المستودع، وبجانبه `assets` و`sw.js` و`manifest.webmanifest` و`.nojekyll`. لا ترفع ZIP وحده.
4. من `Settings → Pages` اختر `Deploy from a branch`، ثم `main` و`/(root)`، ثم `Save`.
5. افتح الرابط الذي يظهر في Pages، مثل `https://YOUR-NAME.github.io/masarifi/`. افتحه مرة متصلًا بالإنترنت وانتظر اكتمال تجهيز العمل دون اتصال.
6. للتثبيت على الهاتف أو التابلت: قائمة المتصفح ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». يظل الموقع نفسه صالحًا للكمبيوتر.

المصدر الرسمي: https://docs.github.com/en/pages/quickstart

## الاستخدام والتحديث

- التثبيت الجديد يبدأ بصندوق واحد بالليرة التركية وبرصيد صفر. غيّر اسمه أو عملته من إعدادات الصندوق قبل تسجيل عمليات فيه. أضف حتى 8 صناديق عملات أو ذهب أو فضة أو نحاس.
- حسابات النسخة القديمة وعملياتها لا تُحذف. يحتفظ البرنامج باسم قاعدة البيانات السابقة لتحديث نفس الموقع والمتصفح.
- عند الانتقال من ملف HTML أو موقع مختلف إلى GitHub، صدّر نسخة JSON من القديم، وافتح الجديد ثم استوردها. بيانات المتصفحات والأجهزة والمواقع المختلفة لا تنتقل تلقائيًا.
- من الإعدادات اختر **أربع فترات بالضبط** من: اليوم، آخر 3 أيام، آخر 7 أيام، آخر 14 يومًا، آخر شهر، آخر 6 أشهر، آخر سنة.
- بطاقات الرئيسية تخص القسم الشخصي أو العمل المحدد، وتجمع المصروف ورسوم التحويل. لا تحسب أصل التحويل كمصروف، ولا تجمع عملات مختلفة في رقم واحد.
- الفترات تنتهي اليوم وتشمل يومي البداية والنهاية؛ الشهر والأشهر والسنة فترات متحركة بالتقويم. يظهر التاريخ داخل البطاقة.
- يحفظ آخر صندوق استخدمته للمصروف أو الإيراد، ويمكن تبديله بسهولة في العملية التالية.

## أسعار الصرف

- مصدر الإنترنت Frankfurter، باختيار ECB أو TCMB من الإعدادات. أسعار مرجعية يومية مع مصدر وتاريخ واضحين، وليست أسعار شراء/بيع أو أسعار تداول لحظية.
- تحديث تلقائي عند الاتصال، بحد أدنى 6 ساعات بين تحديثات ناجحة للمصدر نفسه، أو يدويًا من شاشة الصرف. الاتصال الفاشل لا يحذف آخر نتيجة ناجحة.
- التحويل داخل البرنامج هو تسجيل محاسبي بين صناديقك، ولا يحوّل أموالًا مصرفية حقيقية.
- اختر «تطبيق السعر المحفوظ» داخل نموذج التحويل. السعر الأقدم من تاريخ العملية يحتاج تأكيدًا قبل التسجيل. تبقى المراجعة قبل الحفظ إلزامية.
- المعادن والعملات غير المتاحة بالمصدر تحتاج سعرًا يدويًا. بقي استيراد ملفات TCMB/ECB XML وخيارات TCMB شراء/بيع متاحة للملفات الرسمية التي تحتويها.
- البيانات المالية وصورك لا تُرسل لخدمة أسعار الصرف؛ الطلب يحتوي عملة الأساس ومزود السعر فقط.

توثيق المصدر: https://frankfurter.dev/

## المساعد

مساعد محلي دون إنترنت: يحلل بياناتك ويحسب الأرصدة الحقيقية مع الرصيد الافتتاحي والتحويلات والرسوم، يفهم طلبات شائعة باللغات الخمس، ويجهز الإضافات والتقارير. ليس نموذج ذكاء اصطناعي سحابيًا عامًا مثل ChatGPT.

أمثلة:
- «كم صرفت آخر 3 أيام؟»
- «رصيد صندوق 1»
- «أضف مصروف 250 ليرة طعام» ثم راجع النموذج واحفظ.
- `Dépenses des 3 derniers jours`
- `What is my balance?`

الأوامر غير الواضحة تستدعي سؤالًا أو مساعدة؛ لا ينفذ إضافة مالية دون زر الحفظ. الأوامر التي تشير إلى «الشهر الماضي» قد تعني الشهر التقويمي السابق؛ اقرأ دائمًا النطاق المعروض. بطاقة «آخر شهر» في الرئيسية متحركة.

## الصورة الشخصية والقفل والصور

- اختر اسمك وصورتك من الإعدادات. الصورة تُضغط محليًا وتظهر على الرئيسية والقفل.
- رمز/كلمة مرور جديدة: 6 أحرف أو أرقام على الأقل. كلمات مرور النسخ السابقة تبقى صالحة.
- القفل عند إعادة الفتح، وعند مغادرة التطبيق إن فُعّل، وبعد مدة عدم النشاط المحددة. المحاولات الخاطئة المتكررة تضيف فترة انتظار.
- هذا **قفل خصوصية محلي**، وليس نظام هوية مصرفيًا ولا تشفيرًا لقاعدة البيانات. لا توجد بصمة أو استرجاع كلمة مرور سحابي في هذه الحزمة. احتفظ بنسخة احتياطية خارج الجهاز.
- صور المرفقات تُضغط إلى JPEG حتى 2000 بكسل للجودة العالية أو 1600 بكسل للوضع المتوازن، دون بيانات EXIF، مع 8 صور كحد أقصى لكل سجل. الصورة الشخصية حتى 512 بكسل. جودة HEIC/HEIF تعتمد على دعم المتصفح؛ استخدم JPEG عند تعذّر فتحها.

## التقارير والحفظ

- PDF، وExcel بخلايا قابلة للتعديل، ومشاركة النصوص والعمليات وكشف الصندوق. اللغات الخمس متاحة للتقرير والمشاركة الفردية.
- صفحات PDF المالية تُرسم على صور داخل PDF لدعم الخطوط والاتجاه؛ لذلك النص ليس قابلًا للبحث أو النسخ مثل PDF نصي. Excel يحتفظ بالخلايا الرقمية والنصية والصيغ.
- الصور مضمّنة في ملحق PDF؛ لا تُضمَّن في Excel، وفق توضيح شاشة التصدير.
- النسخة الاحتياطية JSON تضم العمليات والتحويلات والصناديق والمرفقات والإعدادات، بما فيها الصورة الشخصية. لا تضم كلمة القفل؛ فعّل قفل الجهاز الجديد بنفسك.
- التخزين في IndexedDB يخضع لمساحة الجهاز وحصة المتصفح. لا يوجد حد صغير مصطنع لعدد العمليات، لكن لا يمكن ضمان مساحة لا نهائية. «تثبيت الحفظ» يطلب التخزين المستمر، ويظل قرار منحه للمتصفح.
- لا ترفع نسخ JSON الشخصية إلى مستودع GitHub عام. ملفات التطبيق نفسها لا تحتوي على عملياتك.

## الملفات

- `index.html`: نقطة التشغيل.
- `assets/`: المحرك والواجهة والترجمات والصورة والأيقونات ومكتبة التصدير المحلية.
- `sw.js`, `manifest.webmanifest`: التشغيل دون اتصال والتثبيت.
- `tests/`, `package.json`: اختبارات للمطور؛ لا حاجة لتثبيت npm لتشغيل البرنامج.
- `tools/build.py`: يعيد تجميع الترجمات ونسخة HTML ويحدّث نسخة كاش التطبيق بعد تعديل الكود.
- `QA_REPORT.md`: الاختبارات المنفذة والقيود.

لتطوير الملفات: `npm install` ثم `npm test`. لتشغيل محلي عبر HTTP: `python3 -m http.server 8000`. وعند تغيير ملفات المصدر، شغّل `python3 tools/build.py` ثم ارفع الملفات الجديدة معًا.

في التحديثات المستقبلية تبقى النسخة القديمة متماسكة حتى تحميل الجديدة بالكامل. تظهر رسالة تحديث جاهز، واحفظ أي مسودة قبل إعادة التحميل.
