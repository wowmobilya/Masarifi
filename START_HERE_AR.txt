مصاريفي V7.2 — Supabase Auto / Zero‑Setup

الهدف:
- المستخدم النهائي لا يدخل أي إعداد Supabase.
- المستخدم النهائي لا يحتاج بريد أو كلمة مرور.
- يعمل Offline مباشرة ويحفظ محليًا أولًا.
- عند وجود الإنترنت ينشئ هوية Supabase Anonymous تلقائيًا ويزامن.
- Supabase Realtime يستقبل تحديثات السحابة فورًا.

إعداد مالك البرنامج مرة واحدة فقط قبل التوزيع:
1) في Supabase SQL Editor شغّل supabase/setup.sql
2) فعّل Anonymous Sign-Ins في Authentication.
3) شغّل:
   python tools/configure_supabase.py --url "https://PROJECT.supabase.co" --key "sb_publishable_..."
4) ارفع ملفات المشروع الناتجة إلى موقعك/GitHub Pages.

مهم: لا تستخدم Secret key أو service_role داخل التطبيق.
